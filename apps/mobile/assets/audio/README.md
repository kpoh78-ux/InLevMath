# 배경음악 파일 자리

배경음악을 넣는 자리다. **파일이 없으면 헤더의 음악 버튼이 나오지 않고, 앱은 정상적으로 뜬다.**

## 넣는 법 (두 단계)

1. 이 폴더에 `bgm.mp3` 를 넣는다
2. `store/bgmSource.ts` 에서 주석을 바꿔 단다

```ts
export const BGM_SOURCE = require('../assets/audio/bgm.mp3')
// export const BGM_SOURCE: number | null = null
```

파일을 넣는 것만으로 자동으로 잡히게 만들 수 없다 — Metro 는 `require` 를 번들
시점에 해석해서, 없는 파일을 가리키면 `try/catch` 로도 못 막고 번들이 통째로
실패한다. 그래서 가리키는 곳을 한 줄로 몰아 두었다.

## 넣을 때 확인할 것

- **라이선스** — 상업적 이용이 가능한 곡이어야 한다. 학원 운영에 쓰는 앱이므로
  개인 이용 한정 무료 음원은 쓸 수 없다. 유튜브 오디오 보관함·Pixabay·Incompetech 등에서
  라이선스를 확인하고 받는다
- **길이·용량** — 반복 재생되므로 1~3분이면 충분하다. APK 크기를 생각해 5MB 이하 권장
- **음량** — 코드에서 0.35 로 낮춰 튼다 (`store/useBgm.tsx`). 원본이 너무 크면 미리 줄여 둔다
- **분위기** — 공부하면서 듣는 배경이라 가사 없는 곡이 낫다

## 동작 규칙 (`store/useBgm.tsx`)

- 기본은 **꺼짐**. 학원·교실에서 앱을 열었는데 소리가 나면 곤란하므로,
  학생이 직접 켠 경우에만 재생하고 그 선택을 기억한다
- 기기가 무음 모드면 소리를 내지 않는다 (`playsInSilentMode: false`)
- 앱이 백그라운드로 가면 멈추고, 돌아오면 켜져 있던 경우에만 다시 튼다

# 효과음 (선택)

채점 결과·레벨 변화에 맞춰 한 번씩 울리는 짧은 소리다. `store/sfxSource.ts` 에서
넣은 것만 주석을 바꿔 달면 되고, **일부만 넣어도 된다** (나머지는 조용히 넘어간다).

| 파일 | 언제 |
|---|---|
| `sfx-perfect.mp3` | 정답률 95% 이상 |
| `sfx-great.mp3` | 85% 이상 |
| `sfx-good.mp3` | 70% 이상 |
| `sfx-soso.mp3` | 50% 이상 |
| `sfx-poor.mp3` | 50% 미만 |
| `sfx-levelup.mp3` | 레벨업 (축하) |
| `sfx-warn.mp3` | 레벨 다운 근접 (주의) |
| `sfx-leveldown.mp3` | 레벨 다운 (경고) |
| `sfx-quest.mp3` | 퀘스트 안내 |

- 0.5~2초짜리 짧은 소리가 좋다. 길면 다음 화면까지 끌린다
- 레벨이 움직이면 등급 소리 대신 레벨 소리가 울린다 (축하·경고가 더 중요하다)
- **학생이 헤더의 소리 버튼을 끄면 효과음도 함께 꺼진다** — "소리 끔"이라고
  생각한 학생에게 소리가 나면 안 된다
